Contacts

Operations about contacts

Get list of contacts

Retrieve a paginated list of contacts with optional filtering and sorting

Authorizations:
bearerAuth
query Parameters
page
integer >= 1
Default: 1
Example: page=1

Page number for pagination

perPage
integer [ 1 .. 100 ]
Default: 10
Example: perPage=10

Number of contacts per page

sortBy
string
Default: "_id"
Enum: "_id" "name" "phoneNumber" "email" "contactType" "isFavourite" "createdAt" "updatedAt"
Example: sortBy=name

Field to sort by

sortOrder
string
Default: "asc"
Enum: "asc" "desc"
Example: sortOrder=asc

Sort order

type
string
Enum: "work" "home" "personal"
Example: type=work

Filter by contact type

isFavourite
string
Enum: "true" "false"
Example: isFavourite=true

Filter by favourite status

Responses

http://localhost:3000/contacts
https://nodejs-hw-mongodb-3-4hc6.onrender.com/contacts
