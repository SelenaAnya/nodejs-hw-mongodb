📚 API Endpoints

🔐 Authentication

POST /api/auth/register

Register a new user. Requires: name, email, password

POST /api/auth/login

Login user. Requires: email, password. Returns access token.

POST /api/auth/send-reset-email

Send password reset email. Requires: email

POST /api/auth/reset-pwd

Reset password with token. Requires: token, password

👥 Contacts (Requires Authentication)

GET /api/contacts

Get all user contacts with pagination and filtering

POST /api/contacts

Create new contact. Supports multipart/form-data for photo upload

PATCH /api/contacts/:id

Update contact. Supports multipart/form-data for photo upload

DELETE /api/contacts/:id

Delete contact
